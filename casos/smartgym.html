SmartGym

Offline-first mobile app for strength training and progressive overload, with a 12-week periodization engine. Built from scratch as creator and lead developer (2024 – present).

React Native 0.86 Expo SDK 57 TypeScript Jest AsyncStorage Clean Architecture

🔒 The source code of this product is private. This page describes what it does and how it is built, without publishing code. A live walkthrough is available in interviews.

What it does

  • Plans and logs strength workouts with progressive overload and a 12-week periodization cycle that includes deload weeks.
  • Estimates one-rep max (1RM) and computes weekly training volume per muscle group.
  • Works 100% offline: all data is stored on the device, with no server dependency.
  • Uses native device features: fingerprint authentication, calendar sync, voice (TTS) coaching, local notifications and screen keep-awake.

Key engineering decisions

Offline-first by design

The whole app runs without a backend, so it works anywhere and keeps user data on the device.

Pure logic, isolated from the UI

Training math lives in plain TypeScript functions with no UI or device dependencies, which makes it easy to test and reuse.

Clear layer boundaries

~19,600 lines across 65 source files organized into logic/, services/ and context/ following Clean Architecture.

Quality & testing

  • 46 automated Jest unit tests (npm test) covering 1RM estimation, weekly volume per muscle group and 12-week periodization with deloads.
  • Strictly typed TypeScript codebase.
