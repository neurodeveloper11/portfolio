BTC Quant Lab

Research and prediction lab for digital-asset time series: automated data ingestion, feature engineering, machine-learning models validated walk-forward, and a FastAPI inference service. Built as data engineer and lead backend developer (2024 – present).

Python 3.11 pandas NumPy scikit-learn FastAPI Pydantic OpenAPI / Swagger

🔒 The source code of this product is private. This page describes what it does and how it is built, without publishing code. A live walkthrough is available in interviews.

What it does

  • Ingests and cleans multi-timeframe OHLCV market data automatically, including outlier rejection.
  • Builds 25+ vectorized technical features: RSI, MACD, Bollinger Bands, realized volatility, momentum and cyclical (Fourier) components.
  • Trains ensemble models (Random Forest, Gradient Boosting) and evaluates them with walk-forward validation, reporting Sharpe ratio and drawdown.
  • Serves predictions through a FastAPI REST API with Pydantic validation, interactive Swagger docs and inference under 120 ms; includes a desktop UI.

Key engineering decisions

Walk-forward instead of random splits

Random k-fold leaks future information into training on time series. Walk-forward validation always trains on past data and tests on the following period, avoiding lookahead bias.

Risk-aware evaluation

Models are judged on Sharpe ratio and drawdown, not only on accuracy, because a precise but volatile signal can still lose money.

Typed API contract

Pydantic schemas validate every request and response, and the OpenAPI/Swagger docs make the service easy to consume and test.

Quality & testing

  • Vectorized feature computation with pandas and NumPy.
  • Inference latency under 120 ms on the FastAPI service.
