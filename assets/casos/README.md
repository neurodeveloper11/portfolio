# Capturas y videos de los casos de estudio

Coloca aquí las imágenes de cada caso de estudio (sin datos personales ni código):

- `assets/casos/smartgym/01.png`, `02.png`, `03.png`…
- `assets/casos/btc-quant-lab/01.png`, `02.png`, `03.png`…

Luego, en `casos/smartgym.html` o `casos/btc-quant-lab.html`, descomenta el bloque
"SCREENSHOTS & VIDEO" y, si tienes video, reemplaza `VIDEO_ID` por el ID de YouTube
(puede ser un video "no listado") o usa la URL de inserción de Loom.

Recomendación: capturas de 1080×1920 (móvil) o 1600×900 (escritorio), en PNG o WebP.
